# Réponses aux questions du TP

## 1. Quelle est la différence entre Git et GitHub ?
**Git** est un logiciel de gestion de versions qui fonctionne en local sur l'ordinateur.  
**GitHub** est un service en ligne qui héberge des dépôts Git pour les partager et collaborer.

## 2. À quoi sert la commande git init ?
Elle initialise un nouveau dépôt Git vide dans le dossier courant.

## 3. Quelle commande permet d’envoyer un projet sur GitHub ?
C'est la commande  `git push`.

## 4. Pourquoi utilise-t-on les branches ?
Pour travailler sur des fonctionnalités séparées sans toucher à la version principale du code.

## 5. Quelle commande permet de voir l’historique des commits ?
C'est la commande  `git log`.
